# SACRI : nos machines en 3D

Page non publiée par SACRI, non indexée (noindex + robots.txt).
Quatre objets en 3D (tronçonneuse, moteur électrique, pulvérisateur, roulement à billes), à faire tourner, avec « Voir chez moi » en réalité augmentée (Android : .glb ; iPhone : .usdz).
Fiches d'entretien : repères généraux, à faire confirmer par l'atelier SACRI. Le bouton « Demander un devis » prépare un message mais n'envoie rien.

- Moteur électrique (v4) : « Electric motor » par takeboncog, CC BY 4.0, https://sketchfab.com/3d-models/electric-motor-19d028eb4e504314bf909a381b6796eb (mis à l'échelle, textures optimisées).
